# Contributing

Thank you for considering contributing to this project!

There are many ways to contribute. For example:
* Answer question and give input on issues and pull requests.
* Add to the documentation.
* Add example data for testing purposes.
* Report bugs.
* Suggest functionality.
* Write code

To get started, open an issue here on GitHub explaining what you want to do. Then fork the repository and make your changes. When done, create a pull request.

## Contributing code

This converter is written in C# using .NET 8 and .NET Framework 4.8 in Visual Studio 2022. Please try to follow the existing code conventions and style.

## Submitting a Pull Request

Submit a pull request from your fork with a clear description of what you have done and include the relevant issue number, as well as how your change has been tested.
